# Translation units clang-tidy cannot see in the ci_full_defconfig
# compilation database, and the CI variant that analyses each instead.
#
# Format: one "<variant> <path relative to the source root>" pair per line;
# blank lines and lines starting with # are ignored.
#
# The static-analysis target reads this file in two ways (see the clang-tidy
# section of the root CMakeLists.txt):
#
#   * KYTHIRA_TIDY_VARIANT unset (the six ci_full_defconfig shards): every
#     file listed here is dropped from the shard lists, and every remaining
#     file must have a compile command or the target fails. run-clang-tidy
#     skips a file with no compile command without a word, which is how these
#     files went unanalysed until this list existed.
#   * KYTHIRA_TIDY_VARIANT=<variant> (ci.yml's static-analysis-variants job):
#     exactly the files listed for that variant are analysed, and each must
#     have a compile command in that variant's configuration.
#
# A new file that only builds under an optional dependency fails the main
# shards until it is added here under the variant whose defconfig builds it.
#
# Variants and the configuration each one analyses under:
#   dns       configs/ci_dns_defconfig (libldns + Poco DNSSD)
#   gcp       configs/ci_gcp_defconfig with KYTHIRA_GCP_REAL_TESTS=ON
#   ion       configs/ci_ion_defconfig (ion-c)
#   no-cloud  configs/no_cloud_defconfig (no AWS S3, so multi_raft_node
#             builds its "S3 unavailable" test instead of the S3 ones)
